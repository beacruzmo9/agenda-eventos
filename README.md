# Agenda Granada

Web pública que reúne los eventos culturales de Granada (conciertos, teatro, cine, exposiciones…), gratuitos y de pago, actualizada automáticamente cada día.

Cada evento muestra solo datos básicos (título, fecha, lugar, tipo, precio) y enlaza a su fuente original.

Estado: en planificación. Ver `CLAUDE.md` para la arquitectura, el plan por fases y el estado actual.
