# Ciudad en vivo

Web pública que reúne los eventos culturales de Granada (y en el futuro de otras ciudades) (conciertos, teatro, cine, exposiciones…), gratuitos y de pago, actualizada automáticamente cada día.

Cada evento muestra solo datos básicos (título, fecha, lugar, tipo, precio) y enlaza a su fuente original.

Web: https://beacruzmo9.github.io/agenda-eventos/ · Estado y plan en `CLAUDE.md`.

```
npm install
npm run dev     # http://localhost:4321/agenda-eventos/
```
